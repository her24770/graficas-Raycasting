# Música de fondo

Esta carpeta no se sube al repositorio (ver `.gitignore`) porque el archivo
de música tiene copyright.

Para tener música de fondo al correr el juego, coloca aquí un archivo
llamado exactamente:

```
background.mp3
```

Si el archivo no existe, el juego sigue funcionando normalmente, sin
música (se muestra un aviso en la terminal, no es un error).
